# Cerber -- backend

## Tech stack
- Python 3.10+
- FastAPI
- aiomqtt
- InfluxDB async client
- Docker

## Zadanie
Zadaniem jest odbieranie danych z MQTT, przetworzenie ich i zapisanie do bazy danych InfluxDB.
Backend będzie również udostępniał API do pobierania danych z bazy danych.
